## 🌍 Locations Finder — AI-Powered Location Search

## Overview
Locations Finder is a modern web application designed for intelligent location search and exploration. The project combines a robust Spring Boot backend with a responsive React frontend, utilizing Google's Gemini API to process prompts and deliver smart, AI-driven location insights.

## Key Features
- 🔍 **AI Location Search:** Powered by Gemini API to provide dynamic context and search recommendations for locations.
- 🛡️ **Secure Backend Proxy:** API key integration managed safely on the Spring Boot backend server.
- ⚡ **Responsive UI:** Fast and intuitive user experience built with React components.

## Technologies Used
- **Backend (LocationFinder):** Java, Spring Boot, Gemini API
- **Frontend (LocationUI):** React, Next.js, JavaScript, CSS
